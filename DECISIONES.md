# Toma de Decisiones del Proyecto

## 1. Secciones del Sitio
- **Hero / Presentación:** Breve introducción profesional.
- **Sobre mí:** Párrafos describiendo perfil e intereses.
- **Proyectos:** Muestra de proyectos destacados con enlaces.
- **Habilidades:** Clasificación por categorías.
- **Contacto:** Formulario funcional de contacto.

## 2. Paleta de Colores
- **Color Primario (`hsl(220, 78%, 45%)`):** Azul profesional.
- **Fondo (`hsl(0, 0%, 98%)`):** Claro para legibilidad.
- **Texto (`hsl(220, 15%, 20%)`):** Oscuro con alto contraste.
- **Acento (`hsl(180, 60%, 45%)`):** Verde/Turquesa.

## 3. Tipografía
- **Fuente Principal:** Inter, system-ui, sans-serif.
- **Fuente Monoespaciada:** JetBrains Mono, monospace.

## 4. Justificación Técnica
- HTML5 semántico para SEO y accesibilidad.
- CSS modular por archivos.
- JavaScript Vanilla sin dependencias.
